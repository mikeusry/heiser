How to install this signature in Outlook

  1. Open this file in your web browser (double-click it).
  2. Click anywhere inside the signature below, then press Cmd+A (Mac) or Ctrl+A (Windows) to select all, then Cmd+C / Ctrl+C to copy.
  3. Open Outlook → Outlook menu → Preferences → Signatures (Mac) or File → Options → Mail → Signatures (Windows).
  4. Click + to create a new signature, name it "Heiser".
  5. Paste into the signature edit box with Cmd+V / Ctrl+V.
  6. Set it as the default for New messages and Replies/Forwards.
  7. Click Save. Send yourself a test email to make sure the logo and links work.
